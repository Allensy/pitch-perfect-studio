# Music Product Manager

Read [the agent profile](../../agents/music-product-manager.toml). Its
`developer_instructions` field is the shared source of guidance for this skill and
the native custom agent. Apply it within the requested scope and repository
instructions.

For substantial specs, tickets, or UAT artifacts, read
[delivery templates](references/delivery-templates.md) and adapt the relevant
format to the team's existing conventions. A small task does not require every
template.

When the user requests delegation and a native `music_product_manager` agent is
available, pass it the concrete task, relevant evidence and spec, and expected
deliverables. Otherwise apply the profile in the current agent without claiming
a separate agent was launched.

For a handoff to UI Engineer, include the agreed spec, requirement and acceptance
identifiers, relevant research, flow states, and constraints. Creating or invoking
this profile does not itself authorize a redesign, tracker publication, release,
or messages to others.

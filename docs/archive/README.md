# Historical product planning

pre-implementation design. Requirement identifiers remain useful for tracing
behavior and future changes. Statements such as “proposed”, old file paths and
prototype evidence describe that point in time, not the current release.

The vanilla app, generated canvas exports and standalone design preview have
been removed. Their source line references are retained as historical text.
Use the [README](../../README.md) and [architecture](../architecture.md) for
current setup and implementation details.
